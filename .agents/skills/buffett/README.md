## 2. 使用与替换

**支持目录的 skill 环境：**保留上述目录关系，以 `SKILL.md` 作为入口。不要把 `references/` 改名而不同时修改相对链接。

**项目附件或扁平文件环境：**可以逐份上传 Markdown；核心文档允许按原文件名检索，不假定一定存在本地目录或特定 Read 工具。扁平环境中的相对链接未必能够直接点击，但文件名仍可用于检索和读取。

启用新版时，先保存原版备份，再在实际使用环境中移除或明确停用旧版，避免相同主题的旧规则与新规则同时被检索。九份核心文件应整体更新；不要只换入口文件却继续保留旧版估值和卖出规则。

**此包只是本次对话生成的新版副本。**生成文件不等于已经安装、启用或替换项目附件，也不代表访问过任何券商账户。实际项目中的上传、停用旧版或配置变更需单独完成。

## 3. 四种来源标签

| 标签 | 代表内容 | 解释 |
|---|---|---|
| B | 巴菲特公开材料的概括 | 保留来源和语境；不是逐字引语 |
| M | 芒格补充 | 区分原始材料与他人回顾，不冒称巴菲特原话 |
| T | 第三方框架 | 如 Morningstar 的五类护城河 |
| P | 项目实现、分析工具、示例和推导 | 可用于研究，但不冒称巴菲特本人规定 |

没有明确标为 B、M 或 T 的工作流、清单、模型和假设示例，默认属于 P。引用支持某项思想，不表示来源作者也提出了本项目围绕它设计的全部操作步骤。

## 4. 这次修订改变了什么

新版将统一阈值改为行业与情境适配的判断；允许研究结论保留未知；将增长投入、股权薪酬、资本结构和每股价值纳入同一估值链条；把卖出条件从封闭四项扩展为对投资命题、回报、融资及组合约束的持续复核。

机会成本或卖出换仓分析必须优先读取 **Longbridge 当前持仓**，使用实际持仓作为可执行替代对象。读取失败必须披露，不能用聊天记录猜测持仓，也不能以现金或指数比较冒充完整账户比较。纯思想讨论和文档编辑不需要账户读取。

所有账户能力以运行时实际可用的连接和权限为准；本文档不会创建连接。研究授权不等于交易授权，文档没有授予下单、划转或修改账户的权限。

## 5. 证据与维护边界

修订日期不是行情日期，也不表示已经覆盖截至该日巴菲特的全部公开言论。此次只核验来源索引列明的相关历史材料；部分 CNBC 材料只能读到搜索索引中的逐字稿片段或视频简介，索引已单独标注。

文档刻意不保存用户账户快照、当前股价、当前管理层名单、最新持仓、市占率或监管阈值。实际分析时应重新核验必要的动态信息。行业扩展模块是研究问题清单，不是对某家公司当前竞争地位的事实判断。

后续修改应同时维护三个层次：原始来源及核验范围、原则的适用条件、项目工具与执行规则。新增数值门槛必须说明它是示例、筛选参数还是硬性约束，并给出适用对象与理由；不得重新包装成统一的“巴菲特标准”。

## 6. 阅读顺序

先读入口了解规则优先级；一般公司研究再读 `01`、相关行业、`03`—`06` 和 `07`。单项问题按入口的读取表执行，不必每次全文展开。来源有争议、历史案例要用于当前决策，或需要逐字引语时，再回到原始材料。

本包完成的是文档重写、引用链接检查、规则冲突检查与示例算术复核，不是模型实盘验证、投资回测或收益保证。
