## 2. 关键规则修正

### 来源分层

巴菲特概括、芒格补充、第三方工具和项目实现分别标记为 B、M、T、P。去掉未经核实的长引语；保留概括并关联原始材料。CNBC 片段和简介的核验限度单列，不称已经复看完整视频。

### 取消机械门槛

删除统一的 ROIC/ROE、现金转换、债务倍数、利息覆盖、提价比例、NRR、行业估值倍数、安全边际折扣及收入下降 30% 压力测试。相关指标仍可按行业和情境使用，但不以一个数字直接判定优劣或安全。

### 修复价值计算

维持性所有者盈余与增长情景现金分开；实现预测增长的必要投入不能消失。增加股权薪酬、净股数、融资、租赁、非经营现金和穿透收益的口径一致性检查，防止漏算或双算。

### 回购、持有与卖出

回购依据当时价格相对于保守价值、流动性和替代用途，不依据股价涨跌方向。卖出可由关键判断被削弱、回报不足、融资、诚信、组合约束或更好用途触发，不必等到护城河彻底毁坏。

“今天不再买”与“已有持仓应卖”分开；控股企业的经营承诺与上市证券的灵活性分开；研究建议与实际交易授权分开。

### 机会成本落实到实际持仓

涉及机会成本、持仓替代或卖出换仓时，先读取 Longbridge 当前持仓；记录时点、覆盖和币种，再比较已有持仓中的实际候选。失败或不完整必须披露，不从历史聊天推测，不退化成只与现金或指数比较。

此规则来自项目需求，不是巴菲特本人指定。修订文档和纯方法论讨论不触发账户读取；不把个人账户资料写入可分发文档。

## 4. 静态回归检查用例

这些用例用于检查文档逻辑，**不是已经运行过的实盘策略、收益回测或语言模型行为实验**。本次完成了规则位置和交叉一致性检查、相对链接检查、Markdown 结构检查以及示例算术复核；不保证未来任何模型执行都绝无偏差。

| 场景 | 文档必须导向的处理 | 核心位置 |
|---|---|---|
| 对手无法复制核心优势 | 作为支持证据，不计为一个坏的 No | `SKILL` §3、`03` |
| 模型能流畅描述企业，但缺乏竞争证据 | 标明未知或只做条件式研究，不自认证在能力圈 | `01` §1 |
| 企业不适合评估，却要求精确买入价 | 不为模板制造数字 | `SKILL` §7、`06` §5 |
| 维护后现金 100，预测增长需要投入 40 | 对应路径剩余 60，不是 100 加免费增长 | `05` §2 |
| 股权薪酬被 CFO 加回 | 处理经济费用或显式权益变化，不使成本消失或双扣 | `05` §5 |
| 已按资产价值计入持股，又将其收益资本化 | 排除对同一资产的重复计价 | `05` §8、`06` §4 |
| 股价下跌，公司加大回购 | 仍要核对价值、资金和替代用途 | `06` §7 |
| 股价上涨，公司继续回购 | 不直接判错，比较价值增长和执行价格 | `06` §7 |
| 竞争优势削弱但尚未消失 | 允许重新估值及调整持仓 | `07` §2 |
| 公司没变，个人现金需求改变 | 允许从组合和资金期限考虑减仓 | `07` §6 |
| 低增长但持续产出现金 | 评估分配与价格，不自动否决 | `02`、`03` §5 |
| 重资产但增量回报合适 | 纳入必要投入后评估，不按标签淘汰 | `03` §5、`08` §5—6 |
| 保费 200、赔付费用 204、浮存金 200 | 综合成本率 102%，资金成本约 2%，不能称自动高息 | `08` §1 |
| 将浮存金当隐藏资产加回净资产 | 保留真实负债，防止资产与融资价值双算 | `08` §1 |
| 公用事业利润稳定 | 仍需评估监管回收、野火/事故等责任和资本需求 | `08` §5 |
| 银行要求统一收入下降 30% 测试 | 改看信用、存款外流、资产变现和监管资本 | `05` §9、`08` §2 |
| 用户问卖出换仓，账户读取成功 | 用真实当前持仓筛选替代候选，再比较 | `SKILL` §6、`06` §9 |
| 用户问换仓，账户读取失败 | 明示未完成账户比较，不猜持仓、不假装已完成 | 同上 |

| 同一折价对所有企业一刀切 | 改成假设误差、现金回收和生存约束的解释 | `06` §5 |
| 多只股票共享同一需求或技术冲击 | 识别共同风险，不按股票数量宣称安全 | `07` §6 |

## 5. 算例核算口径

- 增长现金示例：`100 + 20 - 20 - 40 = 60`。
- 回购示例：`(100-8)/(10-1) ≈ 10.22`；`(100-12)/(10-1) ≈ 9.78`。
- 保险示例：`204/200 = 102%`；`(204-200)/200 = 2%`。
- 税务示例：`1+(2^20-1)×0.66 ≈ 692,060.50`；`1.66^20 ≈ 25,244.21`。

上述为假设或历史示例的复算，不是股票价格预测、监管标准或用户适用税率。
